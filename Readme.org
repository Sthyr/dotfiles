* My personal config

I try to follow the [[https://wiki.archlinux.org/title/XDG_Base_Directory#User_directories][XDG Base Directory specification]] whenever I can.
Since I use Zsh all my env variables are defined in ~etc/zsh/zshenv~
It may not be the best place but so far I have not encounter any problems.

#+begin_src sh
# XDG environment variables
export XDG_DATA_HOME="$HOME/.local/share"
export XDG_CONFIG_HOME="$HOME/.config"
export XDG_STATE_HOME="$HOME/.local/state"
export XDG_CACHE_HOME="$HOME/.cache"

# Zsh variables
export ZDOTDIR="$HOME"/.config/zsh
export HISTFILE="$XDG_STATE_HOME"/zsh/history

# Rust
export RUSTUP_HOME="$XDG_DATA_HOME"/rustup
export CARGO_HOME="$XDG_DATA_HOME"/cargo

# Renpy
export RENPY_PATH_TO_SAVES="$XDG_DATA_HOME"

# Editor
export EDITOR=helix

# GTK-2
export GTK2_RC_FILES="$XDG_CONFIG_HOME"/gtk-2.0/gtkrc

# GnuPg
export GNUPGHOME="$XDG_DATA_HOME"/gnupg

# Cuda
export CUDA_CACHE_PATH="$XDG_CACHE_HOME"/nv
#+end_src
